# 첨벙! 수영장 안전 탐험대

초등학교 3학년이 쉽고 재미있게 푸는 수영장 안전교육 웹 퀴즈입니다. `index.html`을 브라우저에서 열면 시작됩니다. 서버, 설치, 인터넷 연결이 필요하지 않습니다.

- 총 **10문제**: 객관식 3, 단어 넣기 2, 선 연결 1, 복수 선택 1, OX 1, 순서 맞추기 1, 안전/위험 분류 1
- 한 번에 한 문제, 시간제한 없음, 휴대폰·태블릿·컴퓨터 지원
- 터치 또는 클릭으로 선 연결: 왼쪽 항목을 누른 뒤 오른쪽 항목 선택
- 빈칸에 단어 선택: 빈칸을 누른 뒤 단어 선택. 같은 단어를 반복해서 사용할 수 있음
- 답 확인 후 안전 설명 제공, 틀린 답은 수정하거나 설명을 읽고 다음 문제로 이동
- 첫 번째로 제출한 답만 점수에 반영. 여러 항목이 있는 문제는 모든 항목이 맞으면 1점
- 결과에서 틀린 문제만 복습하거나 10문제 전체를 다시 풀기
- 상단 **선생님 자료**에서 정답·해설 확인, 필요하면 문제지 또는 정답·해설 인쇄
- 이름·학번 입력이나 서버 전송 없음

## 나중에 고학년용으로 수정하기

`questions.js`에 문항, 보기, 정답, 해설을 모았습니다. 초3용 10문제를 기본으로 만들었으며 별도의 고학년 모드는 아직 없습니다. 고학년 수업에서는 같은 문제를 풀고 **왜 그 행동이 안전한지**, **친구에게 어떻게 알려 줄지** 이야기해 볼 수 있습니다.

정답 번호는 보기의 **0부터 시작하는 순서**입니다. `choice`·`ox`는 숫자, 나머지는 숫자 배열을 사용합니다. `multi`는 순서에 관계없이 선택 항목이 일치해야 합니다. `match`는 왼쪽 각 항목에 연결할 오른쪽 번호, `word`·`sort`는 빈칸/행별 번호, `order`는 행동 순서입니다. 유형을 유지하며 제목과 보기를 바꾸면 인쇄 자료도 함께 바뀝니다.
